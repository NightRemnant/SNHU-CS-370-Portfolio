# CS 370 Portfolio Reflection: Pirate Intelligent Agent

## Project Overview

For this project, I worked on a pirate intelligent agent that learns to navigate an 8×8 maze and find treasure using reinforcement learning. The starter code included the `TreasureMaze.py` and `GameExperience.py` files, the neural network model setup, helper functions, and the Jupyter Notebook framework. I was responsible for completing the `qtrain()` function, which handles the agent's training process.

My code implemented the Deep Q-learning training process, including epsilon-greedy exploration, experience replay, neural network training, and target network updates. These features allowed the agent to learn from its actions and improve its decisions over repeated attempts. I trained the agent for up to 1,000 epochs and observed its performance improve as it learned to reach the treasure more consistently.

## What Are My Ethical Responsibilities to the End User and the Organization?

Computer scientists have a responsibility to develop software that is reliable, secure, fair, and respectful of users. When working with artificial intelligence, it is especially important to consider how a system makes decisions, whether its behavior could cause harm, and whether its limitations are understood. I also have a responsibility to protect user data, be transparent about the capabilities of a system, and follow the organization's standards and policies. AI systems should be tested carefully because successful performance in one environment does not guarantee safe or reliable performance in every situation.
